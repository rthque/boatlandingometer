# Rendu — note technique

Nettoyage des triangles, normales cohérentes, reconstruction des profils fins, couverture minimale des lignes à distance, antialiasing et densité de pixels adaptative. Les dimensions de mesure restent distinctes des aides de couverture visuelle.

Les images et rapports détaillés ont été retirés de ce dossier public. Les comparaisons sont conservées dans l’espace privé ; le sous-site TEST offre des planches de rendus chiffrées après connexion.

Le mode allégé, le repli 2D, les gardes de redimensionnement et la reprise de contexte sont conservés. Les performances réelles sur téléphone restent à confirmer. La production et le workflow ne sont pas modifiés par ce cycle.
