# Interaction — note technique

Outils de distance, polyligne et surface, aimantation locale sur la géométrie, unités métriques, annulation et copie explicite. Les mesures restent en mémoire sur l’appareil. Aucun envoi de leurs coordonnées.

L’animation marine est illustrative et ne modifie pas les calculs de hauteur, de référence verticale ou de créneaux. Les données manquantes restent signalées.

Les images et relevés détaillés ont été retirés de ce dossier public. Les rendus de contrôle restent privés et les planches du comparateur sont chiffrées. Les tests navigateur et la fluidité sur appareil doivent compléter les contrôles automatisés.
